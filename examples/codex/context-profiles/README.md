# Threadspan Codex context profiles

These are the portable profile files generated by the installer. Codex profile files live beside `config.toml` as `$CODEX_HOME/<profile-name>.config.toml` and are selected with `codex --profile <profile-name>`.

The always-generated profiles are:

- `gpt-6-astra-default`: 602,000 context tokens; compact at 512,000; medium reasoning. Low remains appropriate for routine bounded work.
- `gpt-5.6-default`: 320,000 context tokens; compact at 272,000.
- `spark`: 128,000 context tokens; compact at 80,000.

The `gpt-6-astra-1m` profile is an Experimental opt-in with a 1,000,000-token context window, compaction at 850,000, and medium reasoning. The current native capture advertises 872K, so this profile needs post-restart native live acceptance before routine use. Every compact threshold is validated to be at most 90% of its context window.

The installer preserves Codex's native picker and catalog. It does not install a replacement `model_catalog_json`.
