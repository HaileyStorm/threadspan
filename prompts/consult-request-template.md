# Consult request packet

## Exact question

State one decision, diagnosis, review target, or uncertainty the consultant should resolve.

## Current state

Summarize what has been implemented or concluded so far. Include the current hypothesis/approach.

## Evidence

List observed behavior, tests, errors, measurements, source findings, or constraints. Distinguish facts from assumptions.

## Relevant artifacts

Include only the smallest code/config/log excerpts needed. Label each artifact with its path or role.

## Constraints and non-goals

State compatibility, performance, security, cost, scope, and timing constraints. State what should not be redesigned.

## Requested answer shape

Examples:

- ranked correctness findings with consequences;
- alternative root causes plus discriminating tests;
- recommendation between options with tradeoffs;
- minimal safe patch plan;
- security/concurrency red-team review;
- explicit disagreement with the current approach where warranted.
