# Hermes Preview host surface

Hermes is not installed or claimed live-certified by this package. The reverse path is a conservative MCP client configuration. The forward full-agent path should target Hermes' `/v1/runs` and `/api/sessions` lifecycle rather than pretending the existing raw Nous model route is a Hermes agent.

The raw Nous provider remains first-class for Consult, Integrated, and the bounded Codex-worker Delegate path. Hermes Agent is a separate optional runtime.
