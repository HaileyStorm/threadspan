# Hermes Preview host surface

Hermes is not installed, signed in, started, or claimed live-certified by this package. The reverse path is a staged read-only MCP client configuration for status, models, accounts, Consult, and raw Integrated routes; reverse Delegate and owner-only controls remain unavailable.

Full Hermes Agent forward execution is unavailable. Current official source constructs each ACP agent with the non-narrowable `hermes-acp` toolset and every enabled Hermes-native MCP server. The documented skip marker prevents background MCP startup only; it does not exclude those servers from each session. A disposable snapshot and rejected permission requests therefore cannot prove advisory Consult or bounded Delegate authority.

Threadspan ships no `hermes-agent` provider, forward route, or native recovery claim. Reconsider forward support only when upstream offers verifiable source-bound/narrowable tool selection and exact exclusion of configured native MCPs; then repeat offline protocol tests and separate native Linux and Windows acceptance. Official Hermes pages also currently conflict on whether ACP sessions restore across process restarts, so recovery remains unavailable until exact-version behavior is resolved.

The raw `nous` provider remains the distinct Consult/Integrated route. Never label the subscription proxy as Hermes Agent or use Hermes ACP as Integrated.
